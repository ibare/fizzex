# 알려진 결함

고치기로 한 것이 아니라 **지금 깨져 있다고 확인된 것**을 적는다. 각 항목은 추측이 아니라
실측에서 나왔고, 재현 방법을 함께 둔다.

수정하면 항목을 지운다 — "해결됨" 으로 남겨 두지 않는다. 이력은 git 이 갖는다.

새 항목은 이 형식을 따른다.

- **증상** — 사용자가 보는 잘못된 결과. 실측값으로 쓴다
- **위치** — 파일과 줄
- **원인** — 왜 그렇게 되는지
- **영향** — 무엇이 막히는지
- **남겨 둔 이유** — 왜 아직 안 고쳤는지

---

지금 열린 항목은 없다.
