# 대표 수식 우선순위 · 구현 현황

학습 콘텐츠에 실제로 등장하는 대표 수식을 **학습 가치와 등장 빈도 순으로** 세우고,
각각이 지금 파이프라인에서 어떤 대접을 받는지 붙여 둔 문서다.
"다음에 무엇을 만들 것인가"를 이 표 하나로 판단할 수 있게 하는 것이 목적이다.

## 정렬 기준

### 학습 가치 — 조작이 곧 이해인 정도

탐색 모드가 학습자에게 주는 것은 **파라미터 조작과 시각화**다. 그러니 값을 바꿔
보는 행위가 개념 이해에 직결될수록 가치가 높다. 수식의 유명세나 난이도가 아니다.

| 등급 | 뜻 | 예 |
|:-:|---|---|
| **A** | 값을 바꾸는 것 자체가 학습이다 | `y = ax + b` 의 기울기, `A = \pi r^2` 의 반지름 |
| **B** | 시각화가 돕지만 정적 설명으로도 상당 부분 전달된다 | 근의 공식, 운동량 |
| **C** | 계산·정의 위주라 조작할 여지가 적다 | 조합 `{}_nC_r`, 지수법칙 |

`E = mc^2` 가 C 인 것이 이 기준을 잘 보여준다 — 가장 유명하지만 조작해 볼 것이 없다.

### 등장 빈도 — 교육과정 노출량

**실측 근거가 없다.** 저장소의 교과서 코퍼스(`src/__tests__/corpus/sources/textbook-formulas-clean.json`,
792건)는 위상수학·초대수 등 대학원 수준이라 학습자 분포를 대변하지 못한다.
현재 등급은 교육과정 기준의 판단값이다.

> **채워야 할 자리**: 실제 학습 콘텐츠 코퍼스가 생기면 이 열을 실측으로 교체한다.
> 그때 `scripts/audit-formula-coverage.ts` 의 `freq` 를 상수 대신 측정값으로 바꾼다.

### 점수

`학습가치(A=3, B=2, C=1) × 등장빈도(높음=3, 중간=2, 낮음=1)` — 1~9.
동점이면 **덜 된 것을 위로** 올린다. 다음에 손댈 것이 먼저 보이도록.

## 읽어낸 것

### 병목은 매처가 아니라 형식의 수다

카탈로그 항목 **223개 중 `form` 을 가진 것은 10개(4.5%)** 다. 형식이 없으면 확정
매칭이 나올 수 없고, 확정이 아니면 진입점도 시각화도 없다. 표의 ✅ 14개가 전부
그 10개 형식에서 나온다.

즉 커버리지를 늘리는 유일한 경로는 **형식을 추가하는 것**이고, 매처를 손보는
일이 아니다.

### 착수 후보 1 — 이름이 맞는데 티어만 미달 (비용 최소)

🟠 중 붙은 이름이 실제와 일치하는 것들. 카탈로그 항목이 이미 있으니 **형식만
추가하면 즉시 ✅ 로 올라간다.** 점수 순으로:

| 6 | 근의 공식 · 원기둥 부피 · 원의 둘레 · 이상기체 상태방정식 | |

**이차함수 꼭짓점형이 특히 아깝다.** 표준형 `y = ax^2+bx+c` 는 ✅ 인데 같은 개념의
꼭짓점형 `y = a(x-p)^2+q` 가 🟠 다. 시각화 4개가 이미 있으니 형식 하나로 그대로
재사용된다.

### 착수 후보 2 — 카탈로그에조차 없는 기본기 (⬜ 29개)

점수 9점인데 매칭이 아예 없는 것들이 학습 콘텐츠의 기초를 이룬다:

> 일차함수 · 정비례 · 반비례 · 속력 · 위치에너지 · 등가속도 속도 ·
> 등차수열 · 등비수열 · 점-기울기 직선

특히 **`y = ax + b`** 는 중학 수학의 중심이고 기울기·절편 조작이 곧 개념인데
카탈로그에 없다. 시각화 관점에서도 이차식보다 만들기 쉽다.

### 착수 후보 3 — 이미 만들었는데 닿지 않는 시각화 2개

`complex-plane-2d`, `linear-transform-2d` 는 spec 과 씬 3개까지 완성돼 있으나
형식의 `visualizers: []` 라서 도달할 수 없다. 원인은 두 시각화가 **식 전체의 값**

것 — `source: 'derived'` 파생 슬롯이 필요하다. 자세한 사유는 `rules/concerns/C9`.

### 확정인데 이름이 어긋나는 것 — 별개 문제

형식 앵커 설계상 **의도된 동작**이다(이름 없는 사례도 같은 형식이면 같은 칩을
받는다). 그러나 학습자가 보는 배너 문구로는 어색하다.

| 수식 | 배너에 뜨는 이름 | 실제 |
|---|---|---|
| `(x-a)^2 + (y-b)^2 = r^2` | 피타고라스 정리 | 원의 방정식 |
| `K = \frac{1}{2}mv^2` | 이차함수 표준형 | 운동에너지 |
| `N = N_0 e^{-\lambda t}` | 지수 성장 | 방사성 붕괴 |
| `A = Pe^{rt}` | 지수 성장 | 연속복리 |

물리 단원에서 운동에너지에 "이차함수 표준형" 배너가 뜨는 것이 옳은지는 제품
판단이 필요하다. 형식 이름("이차식 꼴")을 쓰거나, 카탈로그 이름을 우선하되
형식 칩은 그대로 두는 선택지가 있다.

### 완성형 레퍼런스는 케플러 하나뿐

`astronomy/kepler-third` 만 `parameterConfig` · `effects` · `anchors` ·
`milestones` · `derivedValues` · `constraints` 를 모두 갖췄다.

`parameterConfig` 를 가진 항목은 **223개 중 2개**(케플러, 피타고라스)다. 나머지
221개는 확정 매칭이 되더라도 슬라이더가 `-10 ~ 10, step 0.1` 기본값으로 뜨고 값

생기고 조작의 의미는 비어 있다.**

## 데이터 정합성 이슈

발견된 순서대로. 전부 학습자에게 직접 보이는 값이다.

1. **`freefall-2d` 목성 씬의 `a = 24.79`** 가 형식 슬롯 최댓값(20)을 넘는다.
2. **등가속도 형식 슬롯 기본값 `a = -9.8`** 과 `freefall-2d` 씬 프리셋 `a = +9.807` 의
   부호 규약이 다르다.
3. **케플러 형식의 슬롯 `M`(중심 천체 질량)** 이 두 시각화 어디에도 `userBindings` 에
   없어 조절되지 않는다. 슬롯 `a` 의 최솟값(6771)과 `parameterConfig` 최솟값(6500)도
   어긋난다.
4. **`sine-wave-2d` 의 네 씬이 ω 만 다르다** (A, φ 고정). 진폭·위상은 씬으로 대비되지
   않는다. `compound-interest-2d` 도 네 씬 모두 `n = 1` 이라 복리 횟수가 대비되지 않는다.
5. **중복 개념 항목** — 구의 부피, 원의 넓이, 표준편차가 수준별 카테고리에 이중 등재.
   어느 쪽이 매칭될지 예측하기 어렵다.
6. **`probability` 카테고리**가 선언만 되고 항목이 0개다.
