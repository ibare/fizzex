# 언어 지원

fizzex 는 열 개 언어를 지원한다.

| 코드 | 언어 | | 코드 | 언어 |
|---|---|---|---|---|
| `en` | English (기본) | | `es` | Español |
| `ko` | 한국어 | | `fr` | Français |
| `ja` | 日本語 | | `hi` | हिन्दी |
| `zh` | 简体中文 | | `id` | Bahasa Indonesia |
| `ar` | العربية (RTL) | | `pt` | Português |

## 쓰는 법

### React

```tsx
import { FizzexI18nProvider } from 'fizzex';

<FizzexI18nProvider locale="ja">
  <EditorView />
</FizzexI18nProvider>
```

Provider 가 해당 언어를 내려받아 등록한다. 첫 렌더에서는 설명이 비어 있다가 도착하면 채워진다.

### headless

```ts
import { loadLocale, setLocale } from 'fizzex';

await loadLocale('ja');
setLocale('ja');
```

**부르지 않으면 설명이 비어 나간다.** 조회 API 가 동기라서 데이터가 없으면 기다릴 수가 없다.
크래시하지는 않고 역할 이름 자리에 영문 식별자가 나온다.

## 번들에는 언어가 실리지 않는다

로케일 하나가 약 570KB 다. 열 개를 정적으로 넣으면 5.7MB 가 되고, 영어만 쓰는 호스트도
전부 내려받게 된다. 그래서 `loadLocale` 이 동적 `import()` 로 필요한 언어만 가져온다 —
번들러가 언어별 청크를 만들고 실행 시 하나만 내려받는다.

예외는 두 가지다.

- **UI 문구 영어본** (약 2KB) — 버튼·힌트 마흔 개 남짓. 아무 언어도 받지 않은 상태에서도
  화면이 멀쩡해야 한다.
- **카탈로그 인덱스와 형식 선언** — 설명이 아니라 구조 선언이라 로케일과 무관하다.

## 무엇이 번역되고 무엇이 안 되나

**번역되는 것** — 수식 각 부분의 역할·설명, 화학 원소 118개의 이름, 카탈로그 237항목
(이름·요약·설명·발견자·의의·기호별 뜻), 형식 설명, 탐색 패널 UI, 분석 요약.
언어당 6,093개 문자열이다.

**번역되지 않는 것**

- **코드가 내는 진단** — 파서 경고, zod 스키마 메시지, throw. 전부 영어다.
  사용자에게 보이지 않는 말이므로 앞으로도 영어로 적는다.
- **`unit`·`kind`·`value`·LaTeX 토큰** — 언어 무관 식별자다. `s`, `km`, `N·m²/kg²`,
  `constant`, `\pi` 처럼. 로케일마다 달라지면 같은 값이 다른 것이 된다.
- **카탈로그 매칭** — `catalog/index.json` 의 시그니처만 보므로 어느 언어를 쓰든
  같은 수식이 같은 항목에 매칭된다. 언어는 표시에만 관여한다.

## 언어를 추가하려면

1. `src/locales/types.ts` 의 `LOCALES` 에 코드를 넣는다. 여기가 지원 언어의 단일 진실이다.
2. 데이터 파일을 만든다 — `analyzer/semantic/data/{layer1,layer2,fallback,elements,form}/<코드>.json`
   과 `data/catalog/<코드>/*.json` 25개, `locales/data/ui/<코드>.json`.
3. `src/locales/bundles/<코드>.ts` 를 다른 언어를 본떠 만들고 `registry.ts` 의 `LOADERS` 에 한 줄 넣는다.
4. `pnpm tsx scripts/validate-locale-parity.ts <코드>` 가 통과해야 한다 — 키 구조가 원본과
   같은지, 언어 무관 값이 그대로인지, 한국어가 남지 않았는지 검사한다.

## 알려진 한계

- **카탈로그 두 항목이 한국어 심볼에만 매칭된다.** `percentage` 의 `부분`·`전체`,
  `laffer-curve` 의 `세율`·`세수`·`최적 세율` 이 `elementMeanings` 의 **키**로 들어 있다.
  키는 수식에 나타나는 심볼과 대조되므로, 다른 언어로 쓴 수식에서는 이 기호별 설명이 뜨지 않는다.
  항목 자체의 매칭과 설명은 정상이다.
- **일부 카탈로그 예시가 지역에 묶여 있다.** `anchors` 의 `referenceValue` 가 숫자로 고정이라
  "서울~부산 325km" 같은 기준점을 다른 나라 기준으로 바꾸면 숫자가 맞지 않는다.
  번역본은 비슷한 거리의 현지 기준점으로 옮겨 두었으나, 로케일별 기준값 교체는 별도 과제다.
- **파서 경고가 툴팁으로 노출된다.** `StreamView` 는 `showTooltip` 기본값이 `true` 라
  "Unknown command: \foo" 같은 개발자 문구가 학습자에게 보인다. 번역할 문제가 아니라
  그 자리에 무엇을 보여줄지를 다시 정할 문제다.
